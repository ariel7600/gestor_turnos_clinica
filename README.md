 Sistema de Gestión de Clínica Médica

Trabajo Práctico Integrador para la asignatura **Programación II**. 
El sistema permite gestionar médicos, pacientes, horarios de atención, agenda, turnos e historial médico mediante una interfaz de consola, utilizando archivos binarios ('.dat') para la persistencia de datos.

## Tecnologías utilizadas
* **Lenguaje:** C++ 
* **Paradigma:** Programación Orientada a Objetos (POO)
* **Manejo de datos:** Archivos binarios 
* **Interfaz:** Consola

## Funcionalidades principales
* **Gestión de Médicos:** ABM (Alta, Baja y Modificación), búsqueda por matrícula.
* **Gestión de Pacientes:** ABM, búsqueda por DNI.
* **Horarios de Atención:** Definición de días, horarios y duración de turnos por médico.
* **Agenda:** Generación de disponibilidad a partir de los horarios de atención.
* **Turnos:** Asignación, cancelación y cambio de estados (Asignado, Atendido, Cancelado, Ausente).
* **Historial Médico:** Registro de diagnósticos, tratamientos y anotaciones por paciente.
* **Informes:** Recaudación por mes, turnos por especialidad, por obra social, entre otros.
